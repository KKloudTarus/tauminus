# Security policy

Tauminus handles shell sessions and, in later releases, SSH credentials. Please
report vulnerabilities privately.

## Reporting

Open a private advisory at
https://github.com/KKloudTarus/tauminus/security/advisories/new.

Do not open a public issue for a vulnerability.

Include the affected version or commit, the platform, steps to reproduce, and
the impact you expect.

## Response

- Acknowledgement within 5 working days.
- An assessment and a fix plan within 30 days.
- Credit in the release notes, unless you ask to stay anonymous.

## Supported versions

Tauminus is pre-release. Only the latest commit on `main` receives fixes.
